# Memory Map 要件定義（v2）

## 1. 概要

Memory Map は、カップルが「行った場所の思い出」と「行ってみたい場所」を、ふたりの共有地図で管理するスマートフォン優先のPWAです。将来は友人カップルにも使ってもらうことを想定しています。

| 項目 | 内容 |
|---|---|
| 地図 | Google Maps JavaScript API |
| 画面の仕組み | Vite + React |
| 公開先 | GitHub Actions でビルドし、GitHub Pages で公開 |
| 認証 | Firebase Authentication（Googleログイン） |
| データ | Cloud Firestore（端末間・メンバー間でリアルタイムに同期） |
| 写真 | Cloud Storage for Firebase |
| 場所検索 | Google Places API（New）を、Cloud Functions 経由で呼び出す |
| 主な利用環境 | iPhone の Safari と、ホーム画面に追加したアプリ。PC はたまに見る程度 |

## 2. 目的

- ふたりが同じ地図を、それぞれのスマホから見たり編集したりできる
- 行った場所に、写真・メモ・訪れた日などの思い出を残し、アルバムのように振り返れる
- 行ってみたい場所をリストにして共有できる
- ホストが承認したメンバーだけが使える

## 3. ユーザーと権限

| 立場 | できること |
|---|---|
| ホスト（地図を作った人） | ピンの追加・編集・削除、招待リンクの作成、参加申請の承認・却下、メンバーの解除 |
| メンバー（承認された人） | ピンの追加・編集・削除、写真のアップロード、メンバー一覧を見る |
| 参加申請中の人 | 承認されるのを待つ（地図は見られない） |
| 未ログインの人 | ログイン画面だけを見られる |

- 閲覧だけの権限は、今は用意しない。
- 1人が複数の地図を持てるデータ構造にしておく。ただし、地図を切り替える画面は将来の機能とする。

## 4. 認証とログイン画面

- Googleアカウントでログインする（ポップアップ方式）。
- **ログイン画面**
  - スマホゲームのタイトル画面のように、専用の画像（Memory map、Since 2026/04/01、ふたりのキャラクター、地球）を全画面で表示する。
  - 「Googleでログイン」ボタンは Liquid Glass 調にし、「Since 2026/04/01」の行とキャラクターの間に置く。
  - PC では画像を中央に縦長で表示し、左右は背景画像をぼかして埋める。
- **LINE 内ブラウザ**
  - LINE 内ブラウザでは Google ログインを始めない。
  - 代わりに「ブラウザで開く」と「ログインURLをコピー」の2つのボタンを縦に並べ、ガラス調で表示する。
- ログアウトするとログイン画面に戻る。

## 5. 共有と招待

1. ホストがメニューの「メンバー」で招待リンクを作る（有効期限は7日間）。
2. ホストはリンクをコピーするか、「LINEで送る」で相手に送る。
3. 相手がリンクを開いて Google でログインすると、「参加をリクエスト」画面が表示される。
4. ホストのメニューに、承認待ちの人の名前とメールアドレスが表示される。ホストは承認か却下を選ぶ。
5. 承認されると、相手の画面に自動で地図が開く。
6. ホストは、メンバー一覧（Googleアカウント名とメールアドレス）から、不要なアカウントを解除できる。

- どの地図にも所属していない人が初めてログインすると、「ふたりの地図」が自動で作られ、その人がホストになる。

## 6. 地図画面

- 地図を全画面で表示する。上部に、ガラス調のバー（メニュー、検索欄、「ピン検索」ボタン）を浮かせて置く。
- バーの下に、種別の切り替え（すべて／思い出／行ってみたい）を置く。
- **ピン**
  - 色は種別で分ける：思い出はティール、行ってみたいはバター色。
  - ピンの中には、カテゴリの絵文字を表示する。
- 初めて表示したときは、すべてのピンが画面に収まるように表示する。

### 6.1 ピンの追加

| 方法 | 名前・住所の入り方 |
|---|---|
| 「ピン検索」で候補を選ぶ | 候補の名前・住所・カテゴリを自動で入れる |
| 地図を長押しする（PC は右クリック） | その場所の住所を自動で取得し、場所名の初期値も入れる |
| Google マップ上の施設アイコンをタップする | 施設の名前・住所・種類を自動で入れる |

- どの方法でも、名前と住所は保存前に編集できる。

### 6.2 ピンの情報

- 場所名、住所、緯度・経度、Place ID（内部で保持）
- 種別（思い出／行ってみたい）
- カテゴリと絵文字アイコン：場所の種類から自動で決まる。後から変更できる。
- 訪れた日、メモ
- 写真：1つのピンに最大10枚
- 動画リンク：Google ドライブなどの共有URL
- 作成者、作成日時、更新日時

### 6.3 詳細パネル（下から表示）

- ピンを選ぶと、下からパネルが出る。最初は一部だけが見える状態で、つまみをドラッグかタップすると全体に広がる。
- 内容：写真のスライド表示（タップすると全画面で見られる）、場所名、住所、種別、カテゴリ、訪れた日、メモ、動画リンク
- 操作：編集、ルート（Google マップで道順を開く）、削除（確認あり。写真も削除される）

## 7. メニュー（左からスライドして表示）

- **上部**：キャラクター、地図の名前、メンバーのアイコン
- **思い出アルバム**：思い出のピンを、表紙写真付きのカードで、訪れた日の新しい順に並べる。選ぶとそのピンへ移動し、詳細パネルを開く。
- **行ってみたい**：行ってみたいピンの一覧
- **メンバー**：招待、承認待ちの一覧、メンバー一覧（解除はホストだけ）
- **ログアウト**

## 8. 写真と動画

- スマホのアルバムから、そのままアップロードできる（複数枚を同時に選べる）。
- アップロード前にブラウザで縮小する：本体は長辺2048px、一覧用の小さい画像は400px、どちらも JPEG。
- 写真を見られるのは、その地図のメンバーだけ（Storage のルールで制御する）。
- 写真のダウンロード URL はデータベースに保存せず、表示するときにその都度取得する。
- 動画はファイルを保存せず、共有URLだけを保存する。
  - URL の先を誰が見られるかは、Google ドライブなどの共有設定で管理する。メンバーだけが見られる設定にすること。

## 9. デザイン

- **テーマカラー「風を連れて」**

| 名前 | 色 | 主な用途 |
|---|---|---|
| Deep Shadow | `#0f0b08` | 文字 |
| Ocean Teal | `#197379` | メイン色、思い出ピン、ボタン |
| Mint Blue | `#78bab9` | 補助色 |
| 淡ミント | `#b4d7d9` | 背景の面 |
| Soft Butter | `#f1ebcb` | 背景、行ってみたいピン |

- **書体**
  - 見出し：Cormorant Garamond
  - ロゴ：Great Vibes
  - 本文：Noto Sans JP
- パネル類は Liquid Glass 調（ぼかし＋半透明＋光沢の縁取り）にする。
- iPhone の画面上下の安全領域（ノッチやホームバー）を考慮する。
- 幅720px以上では、詳細パネルを画面の右下にカードとして表示する。

## 10. PWA

- アプリ名は「Memory Map」。テーマ色はティール。
- ホーム画面のアイコンには、ふたりのキャラクターの画像（ターコイズ背景）を使う。
  - `apple-touch-icon` は 180px、manifest 用のアイコンは 192px と 512px を用意する。
  - アイコンを変えたいときは、ホーム画面のアプリを一度削除してから追加し直す（iOS の仕様）。
- Firestore のデータは端末に保存しておく。そのため、電波が弱い場所でも、一度読み込んだピンは見られる。

## 11. 非機能要件

### 11.1 セキュリティ

- **Firestore のルール**：メンバー以外は読み書きできない。メンバーの変更はホストだけができる。参加申請には、有効な招待トークンが必要。
- **Storage のルール**：メンバーだけがアクセスできる。画像ファイルのみ、1ファイル 5MB まで。
- **`searchPlaces`**：許可した送信元からのリクエストで、かつ Firebase の IDトークンが有効な場合だけ受け付ける。
- **API キー**：用途ごとに分け、それぞれ使える場所と API を制限する。

| キー | 用途 | 管理方法 |
|---|---|---|
| Firebase Browser key | 認証・Firestore・Storage | 公開前提。使えるサイトと API を制限 |
| maps-browser-key | 地図表示（Maps JavaScript、Geocoding、Places） | 使えるサイトを制限。値はリポジトリに入れない |
| places-server-key | `searchPlaces` からの検索 | Secret で管理 |

### 11.2 費用

- 目安は「2人で使い、月にピン50件、写真50枚」の規模。この規模なら、各サービスの無料枠に収まる見込み。
- 費用が月1,000円を超えないよう、予算アラートと、各APIの1日の上限を設定する。

### 11.3 性能と可用性

- ログイン画面では認証の部分だけを読み込み、地図やデータベースはログイン後に読み込む。
- 検索結果は、ブラウザのタブを開いている間だけ保存して、同じ検索を繰り返さない。
- Google、Firebase で障害が起きたときは、画面にメッセージを表示する。

## 12. 受け入れ基準

- iPhone の Safari とホーム画面アプリで、ログイン画面が指定の画像で表示され、ボタンが指定の位置にある。
- LINE 内ブラウザでは、外部ブラウザへの案内が表示される。
- ホストが作った招待リンクから相手が参加を申請し、ホストが承認すると、ふたりが同じ地図を見られる。
- 片方がピンを追加・編集すると、もう片方の画面にすぐ反映される。
- 地図を長押しすると、住所が自動で入った「新しいピン」のパネルが開き、名前と住所を編集できる。
- 「ピン検索」と、施設アイコンのタップからピンを追加できる。
- 写真を最大10枚アップロードでき、詳細パネルと思い出アルバムに表示される。
- ピンの種別・カテゴリ・アイコン・訪れた日・メモ・動画リンクを編集できる。
- メニューに、思い出アルバム・行ってみたいリスト・メンバー管理・ログアウトがある。
- ホストが、メンバーを解除できる。
- ホーム画面のアイコンが、指定の画像になっている。
